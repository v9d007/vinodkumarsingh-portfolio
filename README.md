# Vinod Kumar Singh – Developer Portfolio

A modern, responsive portfolio built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Framer Motion**. Showcases skills, experience, projects, and achievements for recruiters and collaborators.

---

## 🚀 Tech Stack
- **React 18** + **TypeScript**
- **Vite 5** (fast dev/build)
- **Tailwind CSS 3** (utility-first styling)
- **Framer Motion 11** (animations)
- **Lucide React** (icons)

## 📦 Features
- Professional, mobile-friendly design
- Animated hero, about, skills, experience, and contact sections
- Skills and experience mapped directly from resume
- Downloadable resume button
- Smooth navigation and scroll
- Contact form (ready for integration)
- Easy deployment to GitHub Pages

## 🛠️ Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run locally:**
   ```bash
   npm run dev
   ```
   Visit [http://localhost:5173/](http://localhost:5173/)
3. **Build for production:**
   ```bash
   npm run build
   ```
4. **Deploy to GitHub Pages:**
   ```bash
   npm run deploy
   ```

## 📁 Project Structure
- `src/components/` – All main sections (Hero, About, Skills, Experience, Projects, Contact, Footer)
- `src/index.css` – Tailwind and custom styles
- `tailwind.config.js` – Tailwind theme and colors
- `vite.config.ts` – Vite config
